安全建議（1 分鐘）
  1. 開專用 workspace：只給 keepsay 用，方便追蹤與撤銷。
  2. 不綁付款方式、關閉自動儲值：預付少量額度即可。
  3. 設定花費上限：在 Console 的 workspace 設月上限。
  4. 如何撤銷：Console → API Keys → 停用或刪除這把金鑰，立即失效。
