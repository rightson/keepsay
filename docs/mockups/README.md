# keepsay UI mockups

- `mobile.html` — iOS main app (M4a) in a phone frame: key setup / skip, model download, home, recording → processing → done, the polish-failed fallback, and settings.
- `desktop.html` — macOS menu bar app (M2) and Windows tray app (M3): menu, recording overlay states, a settings window, and the native Win32 key-entry dialog.
- Open either file directly in a browser (`open docs/mockups/mobile.html`). It needs no server or network. Use the buttons above each frame to jump to a screen, and the toggle in the top right to switch between light and dark.
- These are mockups for UX review only. All numbers and text are placeholders.
